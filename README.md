# Plymouth-theme
Claude sonnet 5 extrta kullanarak kendi bootloader animasyonumu yaptım.

Nasıl kullanılır:

-1 sudo pacman -S plymouth

-2 unzip Roxie-plymouth-theme.zip

-3 sudo cp -r Roxie /usr/share/plymouth/themes/

-4 sudo plymouth-set-default-theme -R Roxie

Sadece cachyOS da denedim ve sorunsuz çalıştı. Diğer dağıtımlar da denemedim.
