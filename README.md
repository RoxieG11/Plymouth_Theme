# Plymouth-theme
Claude sonnet 5 extrta kullanarak kendi bootloader animasyonumu yaptım.

Nasıl kullanılır:

-1 git clone https://github.com/RoxieG11/Plymouth_Theme.git

-2 sudo pacman -S plymouth

-3 unzip Roxie-plymouth-theme.zip

-4 sudo cp -r Roxie /usr/share/plymouth/themes/

-5 sudo plymouth-set-default-theme -R Roxie

Sadece cachyOS da denedim ve sorunsuz çalıştı. Diğer dağıtımlar da denemedim.
