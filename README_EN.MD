# Plymouth theme
I created my own bootloader animation using Claude Sonnet 5 extra.

How to use:

-1 git clone https://github.com/RoxieG11/Plymouth_Theme.git

-2 sudo pacman -S plymouth

-3 Unzip the Roxie-plymouth-theme.zip file

-4 sudo cp -r Roxie /usr/share/plymouth/themes/

-5 sudo plymouth-set-default-theme -R Roxie

I only tried it on CachyOS and it worked flawlessly. I haven't tried it on other providers.
