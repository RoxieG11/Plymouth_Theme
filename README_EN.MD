# Plymouth theme
I created my own bootloader animation using Claude Sonnet 5 extra.

How to use:

-1 sudo pacman -S plymouth

-2 Unzip the Roxie-plymouth-theme.zip file

-3 sudo cp -r Roxie /usr/share/plymouth/themes/

-4 sudo plymouth-set-default-theme -R Roxie

I only tried it on CachyOS and it worked flawlessly. I haven't tried it on other providers.
